# 🔁 10~100회 자율 피드백 루프 실무 운영 가이드

## 1. 루프의 5단계 사이클
1. **[단계 1] Code Proposal**: 타깃 의사코드(Pseudocode)를 기반으로 초안 코드 작성.
2. **[단계 2] Test Harness Execution**: 격리된 샌드박스에서 단위 테스트 및 엣지 케이스 실행.
3. **[단계 3] Defect Scoring**: 입출력 불일치 및 예외 발생 건수를 집계하고 통과율(Pass Rate) 산출.
4. **[단계 4] Self-Healing**: 결손 원인을 역공학 증거(Evidence)와 재대조하여 누락 로직 보강.
5. **[단계 5] Next Iteration**: 차기 회차 코드를 주입하고 1단계로 회귀.

## 2. 수렴 및 종료 규칙
- **최소 10회 검증**: 1회차에 100%가 나오더라도 경계값(Boundary) 스트레스 테스트를 10회까지 지속.
- **연속 3회 100% 달성 시 완결**: 고난도 알고리즘의 경우 오차가 0이 되고 3회 연속 완벽 통과 시 조기 수렴.
- **최대 100회 상한**: 100회 도달 시까지 미해결된 결손은 `UnknownBoundary`로 격리 보고.
