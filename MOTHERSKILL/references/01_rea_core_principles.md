# 🔬 REA 핵심 원리 및 증거 기반 계약 해설

## 1. REA의 동작 철학
- **질문**: "이 앱의 이 기능, 어떻게 돌아가? 똑같이 만들어 줘."
- **기존 방식의 한계**: AI가 소스 코드가 없는 상태에서 인터넷 상식에만 의존해 엉뚱한 코드를 지어냄(Hallucination).
- **REA의 접근법**:
  1. 앱 바이너리, 스크립트, 패키지를 직접 열어 디스어셈블/AST 분석 수행.
  2. 관측된 사실(바이트, 오프셋, 함수 심볼, 매개변수)만을 증거(Evidence)로 추출.
  3. 증거를 바탕으로 의사코드(Pseudocode)와 불확실한 영역(Unknowns)을 명시.
  4. 테스트 하네스를 통해 10~100회 자율 순환하여 원본과 100% 동일한 기능 재현.
